# MoneyBook 기획서 (초안)

> 편한가계부처럼 쓰기 쉽고, 플루니처럼 깔끔한 디자인의 가계부 앱.
> 혼자·부부·가족이 함께 쓰고, 앱스토어 배포까지 목표로 한다.

## 1. 목표

| 항목 | 내용 |
|---|---|
| 사용자 | 개인, 부부·가족(공유 가계부), 일반 배포 |
| 플랫폼 | iPhone, iPad, Android, Mac, Windows (+ 개발 중 확인용 웹) |
| 데이터 | 여러 기기 실시간 동기화, 가족 구성원 간 공유 |
| 참고 앱 | 편한가계부(기능), 플루니(디자인) |

## 2. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 앱 | Flutter | 코드 하나로 모바일·태블릿·데스크톱·웹 모두 지원 |
| 서버/DB | Supabase | 로그인, Postgres DB, 실시간 동기화, 가족 공유 권한(RLS) |
| iOS 빌드 | Codemagic 등 클라우드 빌드 | Mac 없이 앱스토어 빌드 가능 |

## 3. 화면 (목업 기준: `design/mockup/`)

### 모바일
- **홈** (`Main.dc.html`)
  - 월 이동, 검색
  - 예산 사용률 게이지 + 오늘 기준 적정 사용률 표시
  - 남은 예산 / 쓴 돈 / 예산, 하루 사용 가능 금액
  - 캐릭터 자리 (예산 상태에 따라 표정 변화 예정)
  - 인사이트 카드 (예산 속도, 카테고리 초과, 지난달 대비)
  - 카테고리별 예산 진행바
  - 오늘 내역
- **내역 입력** (`Input.dc.html`)
  - 지출 / 수입 / 이체 탭
  - 숫자 키패드 금액 입력, 날짜·시간, 메모
  - 카테고리 8종(식비·카페·교통·쇼핑·생활·문화·의료·기타)
  - 결제수단 선택
  - **문자 붙여넣기**로 카드 승인 문자 자동 인식
- **달력** (`Calendar.dc.html`)
  - 월간 수입/지출/합계
  - 날짜별 수입·지출 금액 표시, 날짜 선택 시 상세 내역
- **통계** (`Stats.dc.html`)
  - 지출/수입 탭, 카테고리 비율 막대 + 순위
  - 최근 6개월 월별 지출, 지난달 대비 비교

### PC
- **대시보드** (`Desktop.dc.html`)
  - 요약(수입·지출·합계·남은 예산), 카테고리별 지출
  - 표 형태 최근 내역 + 입력 줄에서 Enter로 바로 추가
  - "모바일과 동기화됨" 표시

## 4. 기능 목록

### 1차 (MVP)
- [ ] 수입·지출·이체 기록 / 수정 / 삭제
- [ ] 카테고리, 결제수단 관리
- [ ] 월 예산 + 카테고리별 예산, 반원 게이지 (남은 기간 하루 사용 가능 금액)
- [ ] 홈 = 달력 (월 요약, 예산 한 줄, 멤버 필터, 달력, 선택한 날 내역 + "이 날 기록하기")
- [ ] 예산 탭
  - 예산 설정 화면: 총예산, 카테고리별 예산(비우면 예산 없음), 멤버별 개인 한도(선택), 고정지출 추가·삭제
  - "실제로 쓸 수 있는 돈" = 예산 − 쓴 돈 − 아직 안 나간 고정지출, 하루 사용 가능 금액
  - 카테고리: 전체 표시, 초과 → 주의(80% 이상) → 정상 → 예산 없음 순 정렬
  - 고정지출 목록 (나갔어요 / D-day), 지난달 이맘때 대비, 캐릭터 자리는 작게
  - 누가 얼마 썼는지 + 개인 한도 진행률 + 정산하기
- [ ] 통계 탭
  - 기간: 주 / 월 / 연, ‹ › 로 이전 기간 이동, 멤버 필터
  - 합계 + 이전 기간 대비 (진행 중인 달은 "지난달 이맘때"와 비교), 하루 평균
  - 카테고리 비율·순위 + 증감, 누르면 카테고리 상세 (월별 추이, 내역 목록)
  - 이전 기간보다 달라진 점 (더 쓴 곳 / 덜 쓴 곳 TOP 3)
  - 저축 현황 (수입 − 지출, 저축률, 월별 남은 돈)
  - 결제수단별 지출, 큰 지출 TOP 5, 요일별 하루 평균 + 주말/평일 비교 문장
  - 월별 추이 (막대를 누르면 그 달로 이동)
  - 자산은 통계에서 빼고 3차 자산 기능에서 별도 화면으로
- [ ] 홈 달력에서 지난달로 넘겨보기
- [ ] 회원가입·로그인, 기기 간 동기화
- [ ] 마이페이지 (프로필, 내 가계부 목록, 멤버 관리, 설정)
  - 프로필 편집: 닉네임(10자), 프로필 사진 선택/삭제, 내 색 8가지 (함께 쓰는 가계부에서 내 내역 구분용, 다른 멤버와 같은 색이면 안내)

### 2차: 함께 쓰기
- [ ] 가계부 여러 개 (개인용·부부용·가족용 따로 만들기)
- [ ] 멤버 초대 (링크/코드)
- [ ] **누가 썼는지 표시**: 멤버별 색·프로필 아이콘, 멤버별 필터, 멤버별 지출 통계
- [ ] 활동 알림 ("OO님이 점심 9,000원을 기록했어요", 예산 초과 알림)
- [ ] 정산하기 4단계: 멤버 선택 → 기간 → 내역 선택 → "누가 누구에게 얼마"

### 3차: 자산
- [ ] 자산(계좌·카드·현금) 관리
- [ ] 월별 자산 증감 차트 + 자산 상태에 따라 바뀌는 그림
- [ ] 카드 문자 붙여넣기 인식 (Android는 자동 인식 가능, iOS는 붙여넣기)
- [ ] 고정지출·할부

### 나중에 검토
- [ ] 포인트 보상 (무지출 데이, 예산 지키기 등) + 친구·가족 랭킹
  - 연속 기록은 쓰지 않음: 지출 없는 날에 끊기는 문제. 대신 "무지출 데이": 기록이 없는 날이 아니라 사용자가 "지출 없음"을 직접 체크한 날만 셈 (기록 깜빡한 날과 구분). 다음 날 아침 "어제 기록이 없어요" 알림으로 체크 유도
- [ ] 무료/프리미엄 구분: 마이페이지 이름 옆 작은 뱃지로만 표시
- [ ] 포인트로 꾸미기 (캐릭터 아이템, 앱 테마 색)
- [ ] 유료 테마 / 프리미엄 구독
- [ ] 캐릭터 (컨셉 미정)
- [ ] 엑셀 내보내기 / 백업, 위젯
- [ ] 앱스토어·플레이스토어 배포

## 6. 정해야 할 것
- 앱 이름: 미정 (임시 MoneyBook). 방향은 모니모처럼 짧고 리듬감 있고, 작은 것이 모여 커지는 뜻
  - 후보: 알콩, 도담, 차곡, 모닥, 소복, 콩알, 도토리, 토리, 모모, 꼬박, 티끌 (상표·앱스토어 중복 확인 필요)
- 알림 문구 다듬기 (나중에)
- 테마 색 변경: 기본은 스카이, 추가 테마는 네이비+라임처럼 진한 색 + 밝은 포인트 색 대비 조합으로 여러 개 준비 (포인트·유료 테마와 연결)
- 캐릭터 컨셉 (나중에)
- 포인트·꾸미기·유료 정책 (나중에)

## 7. 참고
- 편한가계부: 빠른 입력, 달력, 통계, 문자 인식, 자산 관리
- 플루니: 캐릭터 예산 게이지, 자산 증감 그림, 정산, 마이페이지, 활동 알림
- 말해보카: 포인트 보상, 경쟁, 포인트로 꾸미기
- 기능과 구조만 참고하고 캐릭터·디자인은 직접 만든다
