## 2. IA

모바일 하단 탭 4개 + 가운데 입력 버튼. PC는 왼쪽 사이드바에 자산 메뉴가 하나 더 있어요.

```
가계부 선택 (상단 이름 / PC 사이드바)
│
├─ 홈 (달력)
│   ├─ 월 이동 · 검색 · 알림
│   ├─ 이번 달 지출 · 예산 진행 막대 · 캐릭터 인사이트
│   ├─ 수입 · 남은 돈 · 전월 이월 · 지금 잔액 → 자산
│   ├─ 멤버 필터 (함께 쓰는 가계부)
│   ├─ 달력 → 선택한 날 내역 · "이 날 기록하기" · 무지출 데이 체크
│   └─ 내역 누르기 (수정은 정식 앱에서)
│
├─ 예산
│   ├─ 쓸 수 있는 돈 = 예산 − 쓴 돈 − 아직 안 나간 고정지출, 하루 사용 가능 금액
│   ├─ 반원 게이지 (오늘 기준 적정 사용률)
│   ├─ 카테고리 예산 (초과 → 주의 → 정상 → 예산 없음)
│   ├─ 고정지출 (나갔어요 / D-day, 자동 기록)
│   ├─ 누가 얼마 썼을까요 · 개인 한도 → 정산하기
│   └─ 예산 설정 (총예산, 카테고리, 개인 한도, 고정지출 + 결제수단)
│
├─ ＋ 내역 추가 (어느 화면에서나)
│   ├─ 지출 / 수입 / 이체
│   ├─ 숫자 키패드 (PC는 키보드)
│   ├─ 날짜 · 분류 · 결제수단(들어온 곳 / 보내는 곳 · 받는 곳) · 누가 · 메모(#태그)
│   ├─ 매달 반복 → 고정지출로 등록
│   ├─ 자주 쓰는 내역
│   └─ 문자 붙여넣기 → 금액·날짜·가게·카드 자동 채움
│
├─ 통계
│   ├─ 지출 / 수입 · 주 / 월 / 연 · 멤버 필터
│   ├─ 도넛 + 카테고리 순위 → 카테고리 상세
│   ├─ 달라진 점 · 저축 현황 · 결제수단별 · TOP 5 · 요일별 · 월별 추이
│
├─ 자산 (PC 메뉴 / 모바일: 홈 "지금 잔액", 마이 "내 자산")
│   ├─ 순자산 · 자산 · 부채
│   ├─ 입출금 · 카드 · 현금 · 저축·투자 · 대출 그룹
│   ├─ 자산 상세 (오늘 잔액, 이달 들어온 돈 · 나간 돈, 입출금 내역, 이 자산으로 기록)
│   └─ 자산 추가 · 수정 · 삭제
│
└─ 마이
    ├─ 프로필 편집 · 무지출 데이 · 콩
    ├─ 내 자산 요약 → 자산
    ├─ 내 가계부 · 새 가계부 · 멤버 초대 · 정산하기
    ├─ 가계부 설정: 예산·고정지출 / 분류 관리 / 자산 관리 / 데이터·백업
    ├─ 알림 설정
    └─ 테마 색 · 화면 모드 (시스템 / 라이트 / 다크)
```

## 3. 단식부기 계산 규칙

| 항목 | 규칙 |
|---|---|
| 기록 | 거래 하나를 한 번만 적고, 그 거래가 고른 자산의 잔액을 바꿔요. 차변·대변은 쓰지 않아요. |
| 합계 | 남은 돈 = 수입 − 지출. **이체는 합계에 넣지 않아요** (내 돈이 자리만 옮긴 것). |
| 자산 잔액 | 처음 잔액 + 들어온 수입 − 나간 지출 − 보낸 이체 + 받은 이체 |
| 카드 · 대출 | 카드로 쓴 돈만큼 카드 잔액이 마이너스 = 결제 예정 금액. 통장 → 카드 이체로 갚아요. 대출도 마이너스로 시작해요. |
| 순자산 | 플러스 잔액 합계(자산) − 마이너스 잔액 합계(부채) |
| 전월 이월 | 이번 달 1일 전날까지 그 가계부 모든 자산 잔액의 합 |
| 월말 잔액 | 전월 이월 + 이번 달 수입 − 이번 달 지출 (이체는 가계부 안에서 0) |
| 고정지출 | 매달 정한 날이 지나고 앱을 열면 그 달에 한 번만 자동 기록. 이미 지난 날짜로 새로 등록하면 다음 달부터. |
| 정산 | 고른 내역 합계 ÷ 멤버 수 = 1인 몫. 덜 낸 사람 → 더 낸 사람에게 차액. |
| 예산 | 쓸 수 있는 돈 = 예산 − 쓴 돈 − 아직 안 나간 고정지출. 카테고리는 80% 이상 주의, 100% 초과. |

## 4. 화면별 기능 (프로토타입 반영 상태)

✅ 프로토타입에서 동작 · 🟡 화면만 (서버 필요) · ⏳ 다음 단계

### 홈
- ✅ 달력 + 선택한 날 내역, 이 날 기록하기, 무지출 데이 체크
- ✅ 예산 진행 막대 + 오늘 기준 적정선, 캐릭터 말풍선 인사이트
- ✅ 수입 · 남은 돈 · **전월 이월 · 지금 잔액(→ 자산)**
- ✅ **검색**: 내용 · 분류 · 결제수단 · 사람 · #태그, 찾은 내역 합계
- 🟡 알림 목록 · 멤버 기록 알림
- ⏳ 내역 수정 · 삭제

### 내역 추가
- ✅ 지출 / 수입 / **이체(보내는 곳 → 받는 곳, 합계 제외)**
- ✅ 결제수단 = 그 가계부의 자산 목록 (수입은 들어온 곳)
- ✅ **매달 반복 → 고정지출 등록**, 자주 쓰는 내역, 메모 #태그
- ✅ **문자 붙여넣기** (금액, 날짜, 가게, 카드/통장, 카페·교통·식비 분류 추측)

### 예산
- ✅ 쓸 수 있는 돈, 반원 게이지, 카테고리 예산 정렬, 개인 한도, 정산하기
- ✅ 고정지출 **자동 기록** + 결제수단 지정

### 통계
- ✅ 주·월·연, 지난달 이맘때 비교, 카테고리 상세, 달라진 점, 저축, 결제수단별, TOP 5, 요일별, 월별 추이

### 자산 (새로 추가)
- ✅ 순자산 · 자산 · 부채, 그룹별 합계
- ✅ 자산 상세: 오늘 잔액, 처음 금액, 이달 들어온 돈·나간 돈, 입출금 내역, 이 자산으로 기록
- ✅ 추가 · 수정(이름 바꾸면 내역도 같이 바뀜) · 삭제(쓴 내역이 있으면 막음)

### 마이
- ✅ 프로필 편집, 내 자산 요약, 가계부 목록 · 새 가계부(기본 자산 3개 생성)
- ✅ **분류 관리**: 추가 · 이름 · 색 · 순서 · 삭제(내역은 기타로 이동)
- ✅ **데이터 · 백업**: 이번 달 CSV 복사, 백업 코드 복사 · 불러오기, 예시 데이터로 되돌리기
- ✅ **화면 모드** 시스템 / 라이트 / 다크 (테마 색 3종과 함께)
- ✅ 기록 자동 저장 (브라우저 저장소)
- 🟡 멤버 초대 코드, 알림 설정
